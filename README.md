# NumPy Essentials & Data Manipulation

Welcome to this repository! This project contains a structured collection of Google Colab notebooks and Python scripts designed to leverage the power of **NumPy** for efficient numerical computing, array manipulation, and mathematical modeling.

## 🚀 Project Overview
NumPy (Numerical Python) is the foundational package for scientific computing in Python. This repository demonstrates how to avoid slow Python loops by using vectorised operations on N-dimensional arrays.

## 🛠️ Key Features Covered
- **Array Creation & Inspection:** Handling multi-dimensional arrays, data types, and structural properties.
- **Vectorisation & Broadcasting:** Writing highly optimised code without `for` loops.
- **Indexing & Slicing:** Boolean masking, fancy indexing, and extracting data subsets.
- **Mathematical & Statistical Operations:** Matrix multiplication, linear algebra solvers, aggregation functions (mean, median, standard deviation), and random number generation.

## 💻 Tech Stack
- **Languages:** Python 3.x
- **Libraries:** NumPy
- **Environment:** Google Colab / Jupyter Notebooks
